# Полный резерв ПВ-Системы на VPS Beget «Sage Remy»

Сервер: **Sage Remy**, IP **93.188.184.138**, 2 ядра / 2 ГБ / 30 ГБ, Ubuntu.
Это **второй уровень резерва**, полная копия программы. Работают сайт, расчёты, лицензии,
админ-панель и кабинет организации. Зеркалу не нужны ни poehali.dev,
ни functions.poehali.dev.

| Резерв | Что умеет | Где |
|---|---|---|
| 1. Расчётный (`backup-server`) | только расчёты | хостинг Beget, `сервер.пв-система.рф` |
| 2. Полное зеркало (`mirror-server`) | всё: сайт, расчёты, лицензии, админка, кабинет | VPS Sage Remy |

---

## Шаг 1. Адрес для зеркала

У домена пв-система.рф DNS обслуживает **Яндекс Облако** (ns1/ns2.yandexcloud.net),
а не Beget. Поэтому запись, созданная в панели Beget, в интернете не видна.
Сейчас `сервер.пв-система.рф` не открывается именно по этой причине.

**Вариант А — сразу, без настройки DNS.** Используйте адрес
`93-188-184-138.sslip.io`: он уже указывает на сервер, SSL выпустится автоматически.

**Вариант Б — свой адрес.** Яндекс Облако → Cloud DNS → зона `пв-система.рф` → добавить запись:

| Имя | Тип | Значение |
|---|---|---|
| `резерв` | A | `93.188.184.138` |

В Яндекс Облаке такой адрес обычно вводят в punycode: `xn--b1afah7bd.xn----8sbenozqsbk.xn--p1ai`
(это и есть `резерв.пв-система.рф`).
Через 5–30 минут адрес начнёт работать.

Заодно добавьте там же запись для расчётного резерва:
`сервер` → A → IP хостинга Beget. IP указан в панели Beget, в разделе «Хостинг → Сайты».

## Шаг 2. Войти на сервер

Панель Beget → **Облако → Sage Remy → Терминал (VNC)**. Логин `root`, пароль от сервера.
Можно и с компьютера: в PowerShell выполнить `ssh root@93.188.184.138`.

## Шаг 3. Установить (одна команда, 10–15 минут)

```bash
apt-get update && apt-get install -y git
git clone https://github.com/pvsistema/ventilation-system-design.git /opt/pvs
bash /opt/pvs/mirror-server/deploy/install.sh 93-188-184-138.sslip.io ваша@почта.ru
```

Если выбрали вариант Б, вместо `93-188-184-138.sslip.io` укажите `xn--b1afah7bd.xn----8sbenozqsbk.xn--p1ai`.

Скрипт сам создаёт файл подкачки (без него сборка на 2 ГБ памяти падает),
открывает порты 80 и 443, ставит базу и программу и выпускает SSL.

## Шаг 4. Вписать два секрета

```bash
nano /opt/pvs/mirror-server/.env
```

`ADMIN_PASSWORD` и `OFFLINE_KEY_PRIVATE` возьмите в poehali.dev: **Настройки проекта → Секреты**.
Ключ подписи нужно вставить символ в символ.
Сохраните: Ctrl+O, Enter, Ctrl+X.

⚠️ Сохраните `OFFLINE_KEY_PRIVATE` ещё и отдельно, в надёжном месте. Без него не получится выпускать ключи,
если облако станет недоступно.

## Шаг 5. Перенести лицензии и включить ежечасную копию

```bash
/opt/pvs/mirror-server/.venv/bin/python /opt/pvs/mirror-server/sync_from_cloud.py
systemctl restart pvs-mirror
(crontab -l 2>/dev/null; echo "0 * * * * /opt/pvs/mirror-server/.venv/bin/python /opt/pvs/mirror-server/sync_from_cloud.py >> /var/log/pvs-sync.log 2>&1") | crontab -
(crontab -l; echo "30 4 * * 1 bash /opt/pvs/mirror-server/deploy/update.sh >> /var/log/pvs-update.log 2>&1") | crontab -
```

Первая строка копирует все лицензии, ключи, рабочие места и доступы в кабинет.
Последние две строки включают копирование данных из облака каждый час
и обновление программы каждый понедельник.

## Шаг 6. Проверить

| Адрес | Что должно быть |
|---|---|
| `https://АДРЕС/health` | `"ok": true`, `"database": "ok, licenses=N"` |
| `https://АДРЕС/` | открывается программа |
| `https://АДРЕС/admin` | вход по обычному паролю, видны лицензии |
| `https://АДРЕС/client` | вход клиента, например полиметалл-ук |

## Шаг 7. Подключить зеркало как резерв расчётов

Админ-панель → **Сервер расчёта** → «Адрес аварийного сервера» → `https://АДРЕС/`
→ «Проверить связь» → «Сохранить».

Расчётный резерв на хостинге можно оставить как третий уровень. Или указать здесь зеркало:
оно мощнее и умеет то же самое.

## При аварии poehali.dev

1. Отключите ежечасную копию, иначе после возвращения облака она затрёт данные зеркала:
   выполните `crontab -e` и поставьте `#` перед строкой с `sync_from_cloud`.
2. Сообщите пользователям адрес `https://АДРЕС/` (программа и кабинет организации).
3. Новые ключи выдавайте в `https://АДРЕС/admin`.
4. Когда облако восстановится, перенесите новые ключи в облачную админку вручную
   и только после этого уберите `#` в crontab.

## Важно

- **Оплата VPS.** В панели Beget видно предупреждение: баланса хватит примерно на 9 дней.
  Если сервер отключат за неуплату, резерва не будет. Включите автоплатёж.
- **Снапшот.** Когда всё заработает, сделайте в панели Beget: Sage Remy → «Снапшоты» → «Создать».
  Из снапшота сервер восстанавливается за минуты.
- **Десктопная программа** при аварии продолжает работать по уже активированным лицензиям
  и аварийным ключам. Новую онлайн-активацию она делает только через облако.
