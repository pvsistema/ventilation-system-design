## 4. ПОРЯДОК РАБОТЫ

1. **Выпуск.** Правообладатель в административной панели создаёт ключ: владелец, число мест, срок. Автономный ключ подписывается закрытым ключом Ed25519.
2. **Распространение.** Ключ передаётся покупателю вместе с лицензионным договором.
3. **Активация.** Пользователь вводит ключ: меню «Лицензия» → «Активировать». Онлайн-ключ проверяется сервером; автономный — самой программой без сети.
4. **Управление.** Правообладатель освобождает места, переносит лицензию на другой компьютер, продлевает или отзывает ключ.

С компьютера пользователя на сервер передаются только: ключ, хеш SHA-256 характеристик оборудования, имя компьютера, тип ОС, параметры экрана и версия программы. Файлы проектов и результаты расчётов не передаются. Сервер лицензирования не может управлять программой и устанавливать обновления.
