## 1. НАЗНАЧЕНИЕ ДОКУМЕНТА

Документ содержит порядок установки, активации и первичной проверки работоспособности экземпляра программного обеспечения «ПВ-Система», предоставленного для проведения экспертной проверки.

Программа поставляется в двух вариантах исполнения:

- **настольная (desktop) версия** для операционной системы Windows — устанавливается дистрибутивом;
- **веб-версия** — не требует установки, работает в браузере.

Для экспертной проверки рекомендуется настольная версия: она содержит полный функционал и локальное расчётное ядро.

## 3. СОСТАВ ДИСТРИБУТИВА

Дистрибутив настольной версии представляет собой единый исполняемый файл установщика:

```
PVS-Setup-<версия>.exe
```

В состав дистрибутива входят:

| Компонент | Назначение |
|---|---|
| `PVS.exe` | Основное приложение (оболочка на платформе .NET 8 + WebView2) |
| `server\` | Локальное расчётное ядро (Python, скомпилировано в исполняемый файл) |
| Ресурсы интерфейса | Собранное клиентское приложение (HTML, JavaScript, CSS, шрифты, иконки) |
| `pvs.ico`, `vproj.ico` | Значки приложения и файлов проектов |

Шрифты и все графические ресурсы включены в состав дистрибутива. Загрузка компонентов со сторонних внешних ресурсов при работе программы не выполняется.

## 4. УСТАНОВКА НАСТОЛЬНОЙ ВЕРСИИ

### Шаг 1. Получение дистрибутива

Скачайте файл установщика `PVS-Setup-<версия>.exe` по ссылке, предоставленной правообладателем.

### Шаг 2. Проверка подлинности дистрибутива (рекомендуется)

Сверьте контрольную сумму скачанного файла с опубликованной правообладателем. В командной строке Windows выполните:

```
certutil -hashfile PVS-Setup-<версия>.exe SHA256
```

Полученное значение должно совпадать с эталонной контрольной суммой SHA-256, указанной на странице загрузки.

### Шаг 3. Запуск установщика

1. Запустите файл `PVS-Setup-<версия>.exe`.
2. Подтвердите запрос системы контроля учётных записей (UAC) на повышение прав — установка выполняется с правами администратора.
3. Следуйте указаниям мастера установки.

Каталог установки по умолчанию:

```
C:\Program Files\PVS
```

### Шаг 4. Параметры установки

В процессе установки доступны опции:

- создание значка на рабочем столе;
- регистрация файловой ассоциации для файлов проектов с расширением `.vproj`.

### Шаг 5. Завершение установки

По завершении работы мастера программа готова к запуску. Перезагрузка операционной системы не требуется.

### Тихая (автоматическая) установка

Для развёртывания на нескольких рабочих местах поддерживается установка без диалоговых окон:

```
PVS-Setup-<версия>.exe /SILENT /CLOSEAPPLICATIONS /RESTARTAPPLICATIONS
```

## 5. ПЕРВЫЙ ЗАПУСК И АКТИВАЦИЯ ЛИЦЕНЗИИ

### 5.1. Запуск

Запустите программу одним из способов:

- значок «ПВ-Система» на рабочем столе;
- меню «Пуск» → «ПВ-Система»;
- двойной щелчок по файлу проекта `.vproj`.

При запуске отображается экран загрузки, после чего стартует локальное расчётное ядро и открывается главное окно программы.

### 5.2. Активация

Поддерживаются два способа активации:

**Онлайн-активация.** В окне активации введите лицензионный ключ, выданный правообладателем. Программа обращается к серверу лицензирования и привязывает лицензию к рабочему месту.

**Автономная (офлайн) активация.** Применяется на рабочих местах без доступа в сеть Интернет:

1. в окне активации выберите автономный режим и скопируйте отображаемый идентификатор рабочего места;
2. передайте идентификатор правообладателю;
3. полученный в ответ автономный ключ введите в окно активации.

Автономный ключ защищён криптографической электронной подписью и действителен только для конкретного рабочего места.

### 5.3. Проверка успешной установки

Работоспособность экземпляра подтверждается следующей последовательностью:

1. Открыть меню **«Помощь» → «О программе»** — отображаются версия программы, версия расчётного ядра и состояние подключения.
2. Создать новый проект: **«Файл» → «Создать»**.
3. Построить простейшую сеть: добавить две выработки, соединённые узлами.
4. Задать параметры выработок (длина, сечение, тип крепи).
5. Установить вентилятор на входной выработке.
6. Выполнить расчёт клавишей **F9** или кнопкой **«Расчёт сети»**.
7. Убедиться, что в строке состояния отображается успешное завершение расчёта, а на ветвях появились значения расходов воздуха и депрессий.

Успешное выполнение расчёта подтверждает корректную установку и работоспособность программы.

## 6. ОБНОВЛЕНИЕ ПРОГРАММЫ

Обновление выполняется встроенным механизмом:

1. Программа периодически проверяет наличие новой версии на сервере правообладателя.
2. При обнаружении обновления отображается уведомление с номером новой версии.
3. По команде пользователя выполняется загрузка установочного файла — на экране отображаются полоса загрузки, скорость и оставшееся время.
4. По завершении загрузки автоматически запускается установка, программа перезапускается на новой версии.

Проверку обновлений можно запустить вручную: **«Помощь» → «О программе» → «Проверить обновления»**.

Пользовательские проекты при обновлении сохраняются.

## 7. УДАЛЕНИЕ ПРОГРАММЫ

Удаление выполняется штатными средствами операционной системы:

**«Параметры» → «Приложения» → «Установленные приложения» → «ПВ-Система» → «Удалить»**

Файлы проектов пользователя при удалении программы не затрагиваются.

## 8. ВОЗМОЖНЫЕ ПРОБЛЕМЫ ПРИ УСТАНОВКЕ

| Признак | Причина | Способ устранения |
|---|---|---|
| Установщик не запускается, сообщение о несовместимости | Версия Windows ниже 10 или 32-разрядная система | Установить на Windows 10/11 (64-бит) |
| Ошибка «Отказано в доступе» при установке | Установка запущена без прав администратора либо предыдущая версия программы запущена | Подтвердить запрос UAC; закрыть работающую программу и повторить установку |
| Главное окно остаётся пустым | Отсутствует компонент WebView2 Runtime | Установить Microsoft Edge WebView2 Runtime и запустить программу повторно |
| Расчёт не выполняется, ядро не отвечает | Локальное расчётное ядро заблокировано средством защиты информации | Добавить каталог установки в список разрешённых в антивирусном ПО |
| Не проходит онлайн-активация | Отсутствует доступ к серверу лицензирования | Проверить подключение к сети; при отсутствии доступа использовать автономный ключ |
