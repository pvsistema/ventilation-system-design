## 1. ЯЗЫКИ ПРОГРАММИРОВАНИЯ И КОМПИЛЯЦИЯ

| Часть программы | Язык | Компиляция в объектный код |
|---|---|---|
| Пользовательский интерфейс | TypeScript, JavaScript (React) | **Не компилируется.** TypeScript преобразуется в JavaScript и собирается в набор файлов сборщиком Vite. JavaScript выполняется интерпретатором браузера (WebView2), объектного кода нет |
| Расчётное ядро и серверные функции | Python 3.11 | **Не компилируется в машинный код.** Python — интерпретируемый язык. Для настольной версии модули переводятся в байт-код Python (.pyc) стандартным модулем `py_compile` и упаковываются в исполняемый файл программой PyInstaller |
| Оболочка настольного приложения для Windows | C# (.NET 8) | **Компилируется** в промежуточный код .NET компилятором Roslyn из состава .NET 8 SDK (команда `dotnet publish`) |

Установочный пакет для Windows собирается программой Inno Setup.

Все средства сборки — свободно распространяемые: Node.js и Vite (MIT), Python и PyInstaller (лицензия PSF и GPL с исключением для сборки), .NET 8 SDK (MIT), Inno Setup (бесплатная лицензия). Плата иностранным правообладателям за их использование не производится.

## 2. МЕСТА ХРАНЕНИЯ ИСХОДНОГО ТЕКСТА И ОБЪЕКТНОГО КОДА

| № | Техническое средство | Что хранится | Где размещено |
|---|---|---|---|
| 1 | Платформа разработки poehali.dev (основное хранилище) | Исходный текст всех частей программы с полной историей изменений (система контроля версий Git), серверные функции, база данных лицензий, файловое хранилище дистрибутивов | Серверы на территории Российской Федерации |
| 2 | Хостинг ООО «Бегет», сайт pvsistema.ru (резервная площадка) | Резервная копия собранной программы (веб-версия), резервный сервер расчётов, дистрибутивы | Серверы ООО «Бегет», г. Санкт-Петербург, Российская Федерация |
| 3 | Рабочее место правообладателя | Рабочая копия исходного текста, сборка настольной версии (оболочка .NET, расчётное ядро, установщик) | 453833, Республика Башкортостан, г. Сибай, ул. Куйбышева, д. 12/1 |

Исходный текст и объектный код на иностранных серверах **не хранятся**. Иностранные сервисы хранения исходного кода (GitHub, GitLab.com, Bitbucket) не используются.

Доступ к исходному тексту имеет только правообладатель.

## 3. ПОРЯДОК СБОРКИ

1. Исходный текст изменяется на рабочем месте правообладателя и в среде разработки платформы poehali.dev.
2. Веб-версия собирается и публикуется средствами платформы poehali.dev на её серверах в Российской Федерации.
3. Серверные функции (Python) развёртываются на серверах платформы poehali.dev в Российской Федерации.
4. Настольная версия для Windows собирается на рабочем месте правообладателя (г. Сибай): сборка интерфейса (Vite), перевод расчётного ядра в байт-код и упаковка (PyInstaller), компиляция оболочки (.NET 8 SDK), формирование установщика (Inno Setup).
5. Готовый установщик выкладывается в файловое хранилище платформы poehali.dev и на резервную площадку ООО «Бегет».
