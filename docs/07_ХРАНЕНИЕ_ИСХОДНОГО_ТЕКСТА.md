## 4. ПОРЯДОК ХРАНЕНИЯ И СБОРКИ

1. Исходный текст ведётся в системе контроля версий Git: основное хранилище — платформа poehali.dev (РФ), рабочая копия — на рабочей станции правообладателя (г. Сибай).
2. Веб-версия собирается и публикуется на серверах платформы poehali.dev (РФ).
3. Настольная версия компилируется на рабочей станции правообладателя (г. Сибай): сборка интерфейса → компиляция расчётного ядра в машинный код и его подписание → компиляция оболочки .NET → формирование установщика.
4. Установщик (объектный код) размещается в хранилище платформы poehali.dev (РФ) и в резервной копии на хостинге ООО «Бегет» (РФ). Для каждого установщика публикуется контрольная сумма SHA-256.
5. Резервные копии исходного текста хранятся на рабочей станции правообладателя и на платформе poehali.dev.
