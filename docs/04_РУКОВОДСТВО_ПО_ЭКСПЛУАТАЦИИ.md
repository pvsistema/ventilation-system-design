## 1. ОБЩИЕ СВЕДЕНИЯ

«ПВ-Система» предназначена для построения компьютерной модели вентиляционной сети рудника или шахты, расчёта распределения воздуха, расчёта количества воздуха по забоям, моделирования аварийных режимов при пожаре и взрыве, расчёта противопожарного водопровода и подготовки материалов планов ликвидации аварий.

Программа выпускается в двух исполнениях с одинаковым интерфейсом и функциями:

- **веб-версия** — работает в браузере, установки не требует;
- **настольная версия для Windows** — устанавливается на компьютер, расчётное ядро встроено, работа возможна без доступа в Интернет.

Требования к пользователю: инженерная подготовка в области рудничной вентиляции, знание методик аэродинамического расчёта горных выработок, базовые навыки работы с операционной системой Windows.

Порядок установки изложен в документе «Инструкция по установке экземпляра программного обеспечения».

## 2. НАЧАЛО РАБОТЫ И ЛИЦЕНЗИЯ

### 2.1. Запуск

Настольная версия запускается значком «ПВ-Система» на рабочем столе или из меню «Пуск». Веб-версия открывается в браузере по адресу https://пв-система.рф.

### 2.2. Активация лицензии

1. Откройте **«Файл» → «Лицензия»** (в строке вкладок — кнопка **«🔑 Лицензия»**).
2. Введите лицензионный ключ вида `PVS-XXXX-XXXX-XXXX-XXXX`.
3. Нажмите **«Активировать лицензию»**. Компьютер занимает одно место из числа мест, предусмотренных ключом.

Для рабочих мест без доступа в сеть применяется **аварийный (автономный) ключ**, выдаваемый правообладателем. После активации на кнопке отображается **«✓ Лицензия»**; в окне лицензии видны владелец, срок действия и число занятых мест. Кнопка **«Деактивировать»** освобождает место для переноса лицензии на другой компьютер.

### 2.3. Личный кабинет организации

Организация-владелец лицензии управляет своими ключами в личном кабинете на сайте программы (страница `/client`, вход по логину и паролю, выданным правообладателем). В кабинете отображаются:

- ключи организации, число занятых и свободных мест;
- компьютеры, на которых активирован ключ, и их состояние («На связи» / «Не на связи»);
- аварийные ключи;
- журнал событий.

Компьютер можно **отвязать** (освободить место, например при замене ПК) или **отключить**.

### 2.4. Демонстрационный режим

До активации лицензии программа работает в демонстрационном режиме:

- модель сети — не более 20 узлов;
- сохранение и открытие проектов недоступны;
- импорт из других программ (АэроСеть, Вентиляция 2.0, Ventsim, DXF/DWG) недоступен;
- вкладка «Аварии» (расчёты пожара и взрыва) недоступна;
- печать и экспорт схемы недоступны.

### 2.5. Первый расчёт (быстрый старт)

1. **«Файл» → «Создать»** — новый проект.
2. Инструментом **«Узел»** расставьте узлы — сопряжения, устья стволов, забои.
3. Инструментом **«Ветвь»** соедините узлы выработками: щелчок по первому узлу, затем по второму.
4. Правый щелчок по узлу выхода на поверхность → **«Поверхностный узел (атмосфера)»**. Нужен минимум один такой узел.
5. Выделите выработку и на вкладке **«Вентиляция»** левой панели задайте тип выработки, сечение и коэффициент α.
6. На ленте **«Главная»** выберите значок вентилятора в сетке условных обозначений и щёлкните по выработке; на вкладке **«Вентилятор»** выберите модель, угол лопаток и частоту вращения.
7. Нажмите **F9** или кнопку **«Расчёт сети»**.

После расчёта в строке состояния горит зелёный индикатор **«Сошёлся»** с числом итераций, на выработках появляются подписи расхода.

Отмена действий — **Ctrl+Z**, хранится до 50 последних шагов. При закрытии с несохранёнными правками появляется окно с кнопками **«Сохранить»**, **«Не сохранять»**, **«Отмена»**.

## 5. ИМПОРТ ДАННЫХ ИЗ ДРУГИХ ПРОГРАММ

Команда **«Файл» → «Добавить»**. Импорт доступен при активированной лицензии.

| Источник | Что загружается |
|---|---|
| Модель АэроСеть (`.erp`) | Проект целиком — выгружать ничего не нужно |
| CSV из АэроСети | Координаты X, Y, Z и параметры ветвей; мастер с сопоставлением столбцов |
| Схема Вентиляция 2.0 (`.cdf3`), CSV из Вентиляции 2.0 | Схема, сечения, горизонты, перемычки |
| Модель Ventsim (`.vsm`), CSV из Ventsim 5/6 | Узлы, ветви и их параметры |
| Чертёж DXF / DWG (НаноКАД, AutoCAD, АэроСеть) | Линии и полилинии превращаются в ветви, их концы — в узлы |
| `.vproj`, `.json`, `.xml`, `.txt` | Проекты программы и обменные форматы |

### 5.1. Импорт проекта АэроСети (.erp)

В окне **«Импорт проекта АэроСеть (.erp)»**:

1. Перетащите файл или нажмите **«Выберите файл»**.
2. Отметьте, что переносить: узлы и выработки с сечениями, вентиляторы, перемычки, позиции ПЛА (номера, цвета, выноски), горизонты.
3. Укажите **«Единицы R в файле»**: **«Авто (рекомендуется)»**, «кМюрг» или «Н·с²/м⁸ (СИ)». В режиме «Авто» программа сама определяет единицы и при необходимости пересчитывает сопротивления.
4. Выберите способ добавления: **«Заменить текущую схему»** или **«Добавить к текущей»**.

При импорте:

- модель вентилятора подбирается по названию из каталога;
- учитывается **способ установки ГВУ** — «Внутри перемычки» или «Без перемычки»;
- если на одной выработке стоят несколько вентиляционных сооружений, их сопротивления **суммируются** (сооружения стоят последовательно); перемычка рядом с вентилятором не теряется.

Кнопка **«Показать лог разбора»** выводит подробный протокол чтения файла.

### 5.2. Импорт чертежа DXF / DWG

1. **«Файл» → «Добавить»** → DXF/DWG, перетащите файл в окно.
2. В списке слоёв оставьте галочки на слоях выработок. Кнопки **«Только нужные»**, **«Все»**, **«Снять все»** расставляют галочки разом. Число ветвей обновляется сразу.
3. Нажмите кнопку импорта. Единицы чертежа (мм, см, м) определяются автоматически.

Параметры выработок после импорта задаются вручную (раздел 7).

## 6. ПОСТРОЕНИЕ ВЕНТИЛЯЦИОННОЙ СЕТИ

### 6.1. Инструменты

| Инструмент | Назначение |
|---|---|
| Выбрать | Выделение и перемещение объектов |
| Узел | Добавление узла; щелчок по ветви делит её |
| Ветвь | Выработка между двумя узлами |
| Панорама / Вращать | Перемещение и вращение вида |
| Удалить | Удаление узла, ветви, условного обозначения |
| Текст блок | Надпись на схеме |
| Разделить выработку | Разбиение выработки промежуточным узлом |

Завершение построения — **Escape** или **Enter**.

### 6.2. Узлы

- **Поверхностный узел (атмосфера)** — граничное условие; задаётся в контекстном меню узла.
- **Разорвать связь в узле** — разделить узел на независимые (выработки пересекаются на плане, но не сообщаются).
- **Соединить узлы** — выделить несколько узлов (Ctrl+щелчок) и объединить.
- **Номер узла** и **координаты X, Y, Z** — на вкладке «Параметры» свойств узла.

### 6.3. Ветви

- выделение — щелчок; группа — **Ctrl+щелчок**; подобные объекты — двойное нажатие **S**;
- **«Развернуть ветвь»** (контекстное меню) — изменить направление;
- **«Свойства выделенных (N ветв.)…»** — групповое редактирование;
- **«Копировать параметры ветви»** → **«Применить параметры…»** — перенос параметров с образца.

### 6.4. Удаление выработок

Перед удалением открывается окно с разбором последствий: какие выработки удаляются, какие условные обозначения исчезнут вместе с ними, какие узлы останутся изолированными.

### 6.5. Проверка схемы

Режим **«Проверка»** в выпадающем списке левой панели находит изолированные узлы и фрагменты, ветви нулевой длины, отсутствие поверхностного узла, перемычки без толщины и давления разрушения, подозрительные значения сопротивления. Пороги проверок настраиваются.

### 6.6. Наклонный съезд и перемещение схемы

- **«Схема» → «Наклонный съезд»** — раскладывает высотные отметки по трассе съезда (в том числе спирального) и проверяет уклон.
- **«Схема» → «Перемещение схемы»** — сдвиг всей схемы, видимых или выделенных объектов по X, Y, Z. Вкладка **«Привязка координат»** задаёт смещение до системы координат AutoCAD / «Вентиляции 2.0» по одному узлу.

**Поддерживаемые формы сечения:** круглое, прямоугольное, трапецеидальное, арочное, произвольное (площадь и периметр вводятся напрямую). Длина выработки вычисляется по маркшейдерским координатам узлов.

## 8. УСЛОВНЫЕ ОБОЗНАЧЕНИЯ И ОБОРУДОВАНИЕ

### 8.1. Размещение

На ленте («Главная», «Схема», «Вентиляция») откройте сетку условных обозначений, выберите значок и щёлкните по выработке. Группы: вентиляторы (ГВУ/ВВУ, ВМП), перемычки (бетонная, кирпичная, деревянная, металлическая, **взрывоустойчивая** — зелёный ромб, противопожарная дверь, регулирующая, с вентиляционным окном), аварийные (очаг пожара, место взрыва), противопожарная защита (пожарный кран, гидрант, спринклер, лафетный ствол).

| Действие | Способ |
|---|---|
| Переместить вдоль выработки | Перетаскивание мышью |
| Сдвинуть от выработки | Перетаскивание с Ctrl или Alt |
| Развернуть | Ctrl+R |
| Копировать / вставить / дублировать | Ctrl+C / Ctrl+V / Ctrl+D |
| Удалить | Delete |

Щелчок по значку вентилятора открывает вкладку «Вентилятор»; двойной щелчок по очагу пожара, месту взрыва, перемычке, регулятору ППЗ — соответствующую вкладку.

### 8.2. Настройка вентилятора

На вкладке **«Вентилятор»** задаются:

- модель из каталога; тип установки — ГВУ, ВВУ, ВМП;
- угол установки лопаток, частота вращения;
- реверсивный режим, остановка вентилятора;
- способ установки — внутри перемычки или без перемычки; параметры окна;
- число одинаковых вентиляторов, работающих в параллель.

Рабочая точка (Q, H, КПД) определяется автоматически. Кнопка увеличения графика открывает окно рабочей точки: выбор угла лопаток щелчком по кривой, линия сопротивления сети, сохранение в PNG и выгрузка в Excel.

## 9. МАРКШЕЙДЕРСКИЕ КООРДИНАТЫ И ГОРИЗОНТЫ

### 9.1. Две системы координат

Длины выработок берутся из **маркшейдерских координат** узлов. Перемещение узлов мышью меняет только **координаты отрисовки** — расчёт при этом не меняется.

- **F2** — режим правки маркшейдерских координат: перетаскивание меняет настоящие координаты и длины;
- счётчик **«Сдвинуто узлов»** в строке состояния;
- **«Вернуть на маркшейдерское место»** — для одного узла; **F5** — для всей схемы (с подтверждением);
- **«Зафиксировать текущее как эталон»** — объявить текущее положение выверенным.

### 9.2. Горизонты

Левая панель → **«Горизонты»**: создание, переименование, удаление, видимость, цвет, подложка-картинка плана. Кнопка **«Настройки (план, печать)»** открывает сдвиг горизонта по X, Y, Z и настройки листа печати. **Совмещение по узлам** (зелёная кнопка-прицел): выделите узел на перемещаемом горизонте и узел на основной схеме — программа сама вычислит сдвиг.

## 10. РАСЧЁТ ВОЗДУХОРАСПРЕДЕЛЕНИЯ

### 10.1. Параметры

Лента, группа «Расчёт сети» → **«Параметры»**:

| Параметр | По умолчанию |
|---|---|
| Метод расчёта | Метод Кросса (Андрияшева–Кросса) или МКР (метод контурных расходов) |
| Макс. погрешность | 0,001 Па |
| Макс. число итераций | 5000 |
| Фактор сходимости α | 0,5 |

### 10.2. Выполнение

Клавиша **F9** или кнопка **«Расчёт сети»**. Во время расчёта на кнопке отображается ход вычисления.

Требования к схеме: схема связна, есть хотя бы один поверхностный узел. Остановленный вентилятор напора не создаёт. Если расход сбалансирован, но невязка по давлению превышает допустимую, расчёт не считается сошедшимся: в «Логе» выводится предупреждение с рекомендацией сменить метод или уменьшить фактор сходимости α.

### 10.3. Результаты

- расход Q (м³/с), скорость V (м/с), депрессия ΔP (Па), сопротивление R по каждой выработке;
- стрелки направления движения воздуха; красный цвет — превышена допустимая скорость;
- итог в строке состояния: «Сошёлся» / «Не сошёлся», число итераций;
- кнопка **«Лог»** — журнал расчёта с предупреждениями.

## 11. РАСЧЁТ КОЛИЧЕСТВА ВОЗДУХА (ФНиП № 505)

Расчёт потребности забоев в воздухе по п. 155 ФНиП № 505.

1. **«Справочники» → «Нормы расхода воздуха»** — проверьте нормы.
2. Левая панель → **«Участки»** — создайте участки и привяжите выработки.
3. У каждого забоя — вкладка **«Расход воздуха»**: тип забоя (обязательно), число людей, масса ВВ по углю и породе, время проветривания, дизельная техника.
4. **F9**, затем лента «Вентиляция» → **«Расход воздуха»**.

Потребность считается по четырём факторам (люди, газы взрывных работ по формуле Воронина, дизельная техника, минимальная скорость); в зачёт идёт наибольший, к нему применяются коэффициенты запаса и утечек. Сводная таблица сгруппирована по участкам; галочка **«Только проблемные»**; кнопка **«Excel»** — выгрузка отчёта.

**Вердикт по забою:** «Обеспечено», «Недостаточно воздуха» (с указанием дефицита), «Скорость выше допустимой», «Скорость ниже минимальной», «Данные не заданы».

## 12. ВЕНТИЛЯЦИОННЫЙ СТАВ ТУПИКОВОГО ЗАБОЯ

**Экспорт в Excel** (группа «Анализ») — выгрузка таблиц выработок или узлов по шаблону: «Модель сети», «Расходы воздуха», «Депрессии», «Проверка скоростей», «Оборудование», «Пожар», «Трубопроводы» или свой набор столбцов.

### 13.1. Акт проверки устойчивости вентиляционных режимов при пожаре

1. «Вентиляция» → **«Устойчивость при пожаре»**.
2. Задайте **условия отбора ветвей**: угол наклона не менее (град), длина выработки не менее (м), температура воздуха.
3. Выработки разбираются на четыре группы: наклонные и вертикальные, с нисходящим и восходящим проветриванием. Для каждой выработки рассчитывается степень устойчивости: больше 1 — устойчиво, от 0,3 до 1 — неустойчиво, меньше 0,3 — весьма неустойчиво. Для неустойчивых программа подсказывает сопротивление перемычки, возвращающее режим в норму.
4. Кнопка **«Рассчитать факт опрокидывания»** — проверка опрокидывания струи полным расчётом.
5. Кнопкой **«Заполнить»** раскройте **реквизиты титула** и укажите: организацию, объект, «Утверждает» (должность, ФИО, организация), председателя и членов комиссии, период проверки, период ПМЛЛПА, год утверждения.
6. **«Сформировать акт (Excel)»**.

Акт формируется в файле `.xlsx`, оформлен для печати (лист A4, альбомная ориентация, шрифт Times New Roman, нумерация листов). Состав: титульный лист с грифом «УТВЕРЖДАЮ» и составом комиссии; таблицы № 1–4 по группам выработок; таблица № 5 «Мероприятия»; выводы комиссии и подписи.

### 13.2. ВДС и вентиляционный канал ГВУ

Окно **«ВДС»** перемещается по экрану. Вкладки:

- **«Эквивалентное отверстие»** — по ГВУ со схемы вычисляются суммарная подача, эквивалентная депрессия и эквивалентное отверстие; рудник относится к категории «Легкопроветриваемая», «Средней трудности проветривания» или «Труднопроветриваемая».
- **«Отчёт ВДС»** — сводка по вентиляционным сооружениям и выработкам.

**Расчёт вентиляционного канала ГВУ** («Вентиляционный канал ГВУ — работа в номинальной точке»):

1. Выберите вентилятор; маршрут канала строится автоматически — от выработки с вентилятором до сопряжения с вертикальным стволом. Маршрут можно задать вручную узлами А и Б, поменять их местами, убрать крайнюю выработку.
2. Кнопка **«Подсветить маршрут на схеме»** выделяет выработки канала.
3. Программа определяет номинальную точку вентилятора (подача и напор при максимальном КПД с учётом угла лопаток, оборотов и числа вентиляторов), **рекомендуемое сечение канала** — при котором потери в канале не превышают заданной доли напора (по умолчанию 5 %), и проверяет рабочую точку по расчёту сети: устойчивость, отношение подачи к номинальной, КПД.
4. Блок **«Экономический эффект»**: по тарифу (руб/кВт·ч) и числу часов работы в год вычисляется годовой расход электроэнергии на потери в канале при фактическом и рекомендуемом сечении и экономия.

## 14. АВАРИЙНЫЕ РЕЖИМЫ: ПОЖАР

Требуется действующая лицензия и выполненный расчёт сети (F9).

1. Вкладка **«Аварии»** → **«Установить очаг пожара»** → щелчок по выработке.
2. На вкладке **🔥 «Пожар»** задайте мощность (МВт) или температуру (°C, не выше 1200) и горючий материал: уголь, масло/горючее, деревянная крепь, кабель, конвейерная лента, техника, произвольный. Для техники массы резины, дизельного топлива и масла подставляются выбором машины из справочника «Транспорт».
3. Кнопка **«Расчёт пожара»**. Тепловая депрессия рассчитывается по методике «Норматив (4.5)».

**Результаты:** температура продуктов горения, тепловая депрессия, концентрации CO и CO₂, оптическая плотность дыма, видимость, время задымления каждой выработки; цветовая карта задымления. Анимация задымления — кнопками и ползунком времени внизу экрана (шкала 60–600 мин).

Оценка последствий — «Зона поражения», «Устойчивость при пожаре», «Подбор режима» (раздел 13). Для оценки эвакуации у узлов на вкладке **«👷 Аварии»** задаются рабочие места с численностью, выходы и камеры-убежища.

**Сброс:** «Убрать очаги», «Сбросить пожар».

## 15. АВАРИЙНЫЕ РЕЖИМЫ: ВЗРЫВ

1. **«Аварии»** → **«Установить место взрыва»** → щелчок по выработке.
2. На вкладке **💥 «Взрыв»** выберите источник:
   - **газ** (метан, водород, пропан, ацетилен — объём смеси и концентрация) или **угольная пыль** — расчёт по Методике ВГСЧ (прил. 12 к Уставу ВГСЧ); вид взрыва — детонация, дефлаграция с пылью или без;
   - **заряд ВВ** (ТНТ, аммонит 6ЖВ, гранулит АС-8, игданит, ANFO, эмульсионное, произвольное) — расчёт по ФНП № 494, пп. 816–822: крепь выработки-очага (прил. 29), значение β (нижняя или верхняя граница), суммарное сечение ΣS у заряда, галочка «Породы IX группы и выше».
3. Кнопка **«Расчёт взрыва»**.

Для каждой методики используется одна расчётная модель.

**Результаты:** тротиловый эквивалент, давление и импульс в эпицентре, скорость фронта, радиусы зон поражения; для ВВ — ΣS, приведённый диаметр, принятое β. Зоны: летальная — свыше 100 кПа; тяжёлые поражения — 50–100 кПа; средние — 30–50 кПа; лёгкие — 10–30 кПа; безопасная — менее 10 кПа.

| Кнопка | Действие |
|---|---|
| Показать / Скрыть зоны взрыва | Окраска схемы по давлению во фронте |
| ▶ / ⏸ / ⏮, ползунок R | Анимация движения ударной волны |
| ⏭ До конца сети | Окрасить всю схему сразу |
| Диаграмма перемычек | Нагружение каждой перемычки во времени: разрушена или устояла |
| Толщина перемычки | Калькулятор толщины взрывоустойчивой перемычки (РБ № 343, пп. 25–27) с актом в Excel |
| Протокол в Excel | Протокол расчёта |
| Снять разрушения / Сбросить взрыв | Сброс результатов |

Если давление разрушения перемычки не задано, применяется типовое по материалу: бетон 0,2 МПа, кирпич 0,05 МПа, дерево 0,01 МПа, металл 0,02 МПа.

## 16. ПРОТИВОПОЖАРНЫЙ ТРУБОПРОВОД (ППЗ)

### 16.1. Построение

1. На выработках с трубопроводом — вкладка **«Трубы»**: диаметр, материал (сталь, чугун, полиэтилен, ПВХ, асбестоцемент, прочее), длина, шероховатость.
2. На узле-источнике — вкладка узла «Трубы», тип **«Резервуар с водой»** (ёмкость, начальный напор).
3. На узлах-потребителях — «Пожарный кран», «Гидрант», «Спринклер»; модель ствола из справочника (РС-50, РС-70, СРК-50, РСП-50, РСП-70, РСК-50, РСКЗ-70, ВВР-1, «ПУРГА-5», «ПУРГА-7», НПГУ-1).

Гидравлический расчёт выполняется автоматически при изменении данных водопровода. Стальные и чугунные трубы в режиме «По материалу» рассчитываются по формуле Шевелёва для труб в эксплуатации (λ = 0,021/d^0,3).

### 16.2. Проверка по нормативу

«Вентиляция» → **«Проверка ППЗ»** — пакетная проверка всех точек водоразбора. Нормативы по умолчанию (изменяются в окне): свободный напор не менее 0,6 МПа и не более 1,5 МПа; расход через ствол не менее 30 м³/ч; время работы от запаса воды 180 мин; два одновременно работающих ствола; скорость воды не более 5 м/с. Результат — акт с перечнем необеспеченных точек и причинами.

### 20.1. Печать

**Ctrl+P** или кнопка «Печать»: принтер, число копий, формат (A4–A0 или произвольный), ориентация, поля, масштаб, шаблоны настроек. На листе: рамка и штамп, блок «УТВЕРЖДАЮ», блоки «СОГЛАСОВАНО» и «Разработал», легенда, блок «Маршруты профилактического обследования». Блоки перетаскиваются и редактируются прямо на схеме. Каждый горизонт может иметь собственный лист: «Горизонты» → «Настройки (план, печать)» → «Слой печати».

Печать и экспорт выполняются в режиме «Чертёж».

### 20.2. Экспорт

| Куда | Форматы |
|---|---|
| Окно печати | SVG; PDF (растровый и векторный); PNG, PNG HQ (72–600 dpi); JPG, BMP, TIFF |
| «Файл» → «Экспорт» | `.vproj`; PDF; АэроСеть (`.erp`); Вентиляция 2.0 (`.cdf3`); водоснабжение для Вентиляции 2.0 (`.hdr`); CSV |
| «Экспорт в Excel» | `.xlsx` — таблицы выработок, узлов и результатов |
| Отдельные расчёты | Акт устойчивости, протокол взрыва, акт толщины перемычки, отчёт по расходу воздуха, МПО — `.xlsx` |

### 20.3. Данные ОПО

Кнопка **«Данные ОПО»** на вкладке «Главная» — паспорт опасного производственного объекта: тип, класс опасности, признаки опасности, учитываемые горизонты. Протяжённость выработок и трубопроводов, количество перемычек и вентиляторных установок вычисляются по схеме автоматически.

## 22. ТИПИЧНЫЕ ЗАТРУДНЕНИЯ ПРИ РАБОТЕ

| Признак | Причина | Действия |
|---|---|---|
| Расчёт не сходится | Нет поверхностного узла, схема несвязна, нестабильная сеть | Режим «Проверка» левой панели; снизить фактор сходимости α до 0,2–0,3; увеличить число итераций; попробовать метод МКР; открыть «Лог» |
| Нулевой расход в выработке | Нет источника тяги, вентилятор остановлен, выработка перекрыта глухой перемычкой | Проверить вентилятор и перемычки |
| Вентилятор вне паспортной характеристики | Рабочая точка вне характеристики | Проверить сопротивление сети, угол лопаток, модель вентилятора |
| После импорта АэроСети расходы не совпадают | Неверно определены единицы сопротивления | Повторить импорт, указав «Единицы R в файле» вручную |
| Не хватает воздуха в тупиковом забое | Мал диаметр рукава, длинный став | Увеличить диаметр через «Изменить весь став», затем лопатки или модель ВМП |
| Вкладка «Аварии», импорт, сохранение недоступны | Демонстрационный режим | Активировать лицензию |
| Расчёт пожара или взрыва не запускается | Не выполнен расчёт сети | Нажать F9 и повторить |
| Печать недоступна | Включён объёмный просмотр «Модель» | Вернуться в режим «Чертёж» |
| Длины выработок изменились после перемещения | Узлы двигались в режиме F2 | Вернуть узлы на маркшейдерские места (F5) |
