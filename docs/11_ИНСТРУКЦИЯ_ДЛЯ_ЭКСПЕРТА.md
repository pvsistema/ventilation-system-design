## 3. СИСТЕМНЫЕ ТРЕБОВАНИЯ

- Windows 10 версии 1809 (64-разрядная) или новее, Windows 11; 2 ядра, 4 ГБ ОЗУ, 500 МБ на диске.
- Компонент Microsoft Edge WebView2 Runtime. Он входит в Windows 11 и обновлённые сборки Windows 10. Если на тестовой машине нет ни WebView2, ни Интернета, установите автономный пакет «WebView2 Runtime — Evergreen Standalone Installer (x64)» с сайта Microsoft.
- Права администратора для установки.
- **Подключение к Интернету для проверки не требуется**: расчётное ядро работает на компьютере, лицензия проверяется по автономному ключу.

## 4. УСТАНОВКА

1. Скачайте установщик по ссылке из раздела 1.
2. Запустите `PVS-Setup-{{VERSION}}.exe`, подтвердите запрос UAC.
3. Следуйте мастеру. Каталог по умолчанию: `C:\Program Files\PVS`. Перезагрузка не нужна.

Если Windows SmartScreen покажет предупреждение — нажмите «Подробнее» → «Выполнить в любом случае».

---

## 5. АКТИВАЦИЯ

1. Запустите «ПВ-Система» (значок на рабочем столе или меню «Пуск»).
2. Откройте окно лицензии: меню **«Файл» → «Управление лицензией»** (при первом запуске без лицензии окно может открыться само).
3. Вставьте ключ эксперта из раздела 2 в поле ключа и нажмите **«Включить аварийный режим»**.
4. В окне лицензии появится статус «Аварийный режим (оффлайн)» с владельцем «Эксперт Российское ПО» — все функции доступны.

## 6. ПРОВЕРКА РАБОТОСПОСОБНОСТИ (5 МИНУТ)

1. «Файл» → «Создать».
2. Нарисуйте две выработки, соединённые узлами; задайте сечение.
3. Правой кнопкой по крайнему узлу → «Поверхностный узел (атмосфера)».
4. Установите вентилятор на выработке, выберите модель на вкладке «Вентилятор».
5. Нажмите **F9** («Расчёт сети»). В строке состояния — «Сошёлся», на ветвях — расходы и депрессии.
