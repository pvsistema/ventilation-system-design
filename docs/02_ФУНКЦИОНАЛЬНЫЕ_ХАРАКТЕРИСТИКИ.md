## 1. НАЗНАЧЕНИЕ И ОБЛАСТЬ ПРИМЕНЕНИЯ

### 1.1. Назначение

«ПВ-Система» — специализированный программный комплекс класса САПР для проектирования, компьютерного моделирования и инженерного расчёта систем вентиляции и противопожарного водоснабжения подземных горных выработок (шахт и рудников).

Программа обеспечивает решение следующих производственных задач:

- построение и ведение компьютерной модели шахтной вентиляционной сети;
- расчёт распределения воздушных потоков в сети произвольной сложности;
- моделирование аварийных вентиляционных режимов при подземных пожарах и взрывах;
- гидравлический расчёт пожарно-оросительного водоснабжения;
- подготовка расчётных материалов для планов ликвидации аварий (ПЛА);
- оформление и выпуск проектной и отчётной документации.

### 1.2. Область применения

- проектные и научно-исследовательские организации горного профиля;
- службы аэрологической безопасности и вентиляции горнодобывающих предприятий;
- военизированные горноспасательные части (ВГСЧ);
- разработка и актуализация планов ликвидации аварий;
- воздушно-депрессионные съёмки (ВДС) и адаптация компьютерных моделей вентиляционных сетей.

### 1.3. Целевые пользователи

Горные инженеры, проектировщики систем вентиляции шахт и рудников, специалисты по промышленной и аэрологической безопасности, работники ВГСЧ.

## 2. ПЕРЕЧЕНЬ ФУНКЦИОНАЛЬНЫХ ХАРАКТЕРИСТИК

### 2.1. Построение и редактирование модели вентиляционной сети

Программа обеспечивает создание графовой модели сети горных выработок:

- построение сети из **узлов** (сопряжения выработок) и **ветвей** (выработки) с трёхмерными координатами X, Y, Z;
- привязка элементов сети к горизонтам и участкам месторождения;
- графический редактор схемы с добавлением, разделением, перемещением и удалением выработок;
- автоматическая и ручная нумерация узлов и ветвей;
- копирование, зеркальное отражение и групповое редактирование фрагментов сети;
- нанесение текстовых блоков, условных обозначений и пояснительных надписей;
- отмена и повтор выполненных действий.

**Поддерживаемые формы поперечного сечения выработок:**

| Форма сечения | Задаваемые параметры |
|---|---|
| Круглое | Диаметр |
| Прямоугольное | Ширина, высота |
| Трапецеидальное | Нижнее основание, верхнее основание, высота |
| Арочное (сводчатое) | Ширина, высота прямой части, стрела свода |
| Произвольное | Площадь сечения и периметр задаются непосредственно |

Для каждой формы автоматически вычисляются площадь поперечного сечения S, периметр P и гидравлический диаметр Dh = 4S/P.

### 2.2. Расчёт аэродинамического сопротивления выработок

Реализованы четыре независимых способа определения аэродинамического сопротивления:

**Способ 1. По коэффициенту аэродинамического сопротивления (формула Аткинсона):**

```
R = α · P · L / S³
```
где α — коэффициент аэродинамического сопротивления, 10⁻⁴ Н·с²/м⁴; P — периметр, м; L — длина выработки, м; S — площадь сечения, м².

**Способ 2. По типу крепи и состоянию поверхности** — с использованием встроенного справочника, содержащего 11 типов поверхностей выработок:

| Тип поверхности выработки | α, ×10⁻⁴ |
|---|---|
| Воздухоподающая выработка без неровностей | 9 |
| Ствол с тюбинговой крепью | 15 |
| Бетонная крепь гладкая | 18 |
| Незакреплённая ровная порода | 30 |
| Бетонная крепь с неровностями до 50 мм | 36 |
| Ствол со скиповым подъёмом | 50 |
| Анкерная крепь | 55 |
| Металлическая арочная крепь | 65 |
| Незакреплённая выработка, рваный контур | 100 |
| Деревянная рамная крепь | 110 |
| Очистной забой (лава) | 200 |

**Способ 3. По эквивалентной шероховатости (формула Альтшуля):**

```
R = λ · L · P / (8 · S³),   λ = 0,11 · (Δ/Dh + 68/Re)^0,25
```

**Способ 4. Непосредственный ввод** значения сопротивления инженером по данным воздушно-депрессионной съёмки.

**Расчёт вентиляционных трубопроводов:**

```
R = 6,48 · α · L / D⁵
```

Встроен справочник коэффициентов сопротивления трубопроводов, содержащий 7 позиций: стальные трубы (новые, с лёгкой, умеренной и сильной коррозией), гибкие вентиляционные рукава (гладкие новые, стандартные, бывшие в употреблении с повреждениями).

Дополнительно вычисляются: скорость воздуха V = Q/S, число Рейнольдса, депрессия ΔP = R·Q·|Q|, мощность воздушного потока.

### 2.3. Расчёт воздухораспределения в вентиляционной сети

Основная расчётная функция программы — определение расходов воздуха и депрессий во всех ветвях сети на основе законов Кирхгофа (баланс расходов в узлах, баланс депрессий в независимых контурах).

**Реализованные методы решения:**

- **метод Хэрди-Кросса (метод контурных расходов)** — итерационное решение по независимым контурам с последовательными приближениями;
- **метод контурных расходов с адаптивным демпфированием** — для сетей повышенной сложности и трудной сходимости.

**Параметры расчёта:**

- невязка сходимости по расходу — настраиваемая, по умолчанию 0,01 м³/с;
- контроль невязки по депрессии;
- максимальное число итераций — до 5000;
- коэффициент демпфирования — настраиваемый.

**Учитываемые факторы:**

- напорные характеристики вентиляторов;
- **естественная тяга** — расчёт по разности плотностей воздуха с учётом высотных отметок узлов: h = ρ·g·(z₁ − z₂), плотность воздуха определяется по температуре, влажности и барометрическому давлению;
- **геотермический градиент** (изменение температуры пород по глубине, °C на 100 м);
- тепловая депрессия при аварийных режимах;
- минимальный расход в тупиковых выработках (диффузионное проветривание).

**Результаты расчёта:**

- расход воздуха, скорость и депрессия по каждой ветви;
- абсолютное давление в каждом узле;
- число независимых контуров сети;
- достигнутые невязки по расходу и давлению, число выполненных итераций;
- **диагностика модели**: разрывы топологии сети, дисбаланс расходов в узлах, работа вентилятора за пределами паспортной характеристики;
- журнал расчёта.

### 2.4. Каталог вентиляторов и определение рабочей точки

Встроенный справочник вентиляторов главного, вспомогательного и местного проветривания. Напорная и энергетическая характеристики задаются полиномиальной аппроксимацией:

```
H(Q) = h₀ + h₁·Q + h₂·Q²      η(Q) = e₀ + e₁·Q + e₂·Q²
```

**Каталог содержит характеристики вентиляторов отечественного производства**, в том числе центробежных ВЦ-15, ВЦ-25, ВЦД-31,5, ВЦД-31,5М2, ВЦД-32, ВЦД-47У и осевых ВО-18/12АВР, ВОД-16АВ, ВОД-21, ВОД-30, ВОД-40. Каталог допускает пополнение характеристиками произвольных вентиляторов по паспортным данным.

**Учитываемые режимы и параметры:**

- угол установки лопаток рабочего колеса (для регулируемых машин — до 7 характеристик на вентилятор);
- частота вращения рабочего колеса с пересчётом характеристики;
- реверсивный режим проветривания;
- параллельная работа вентиляторов (суммирование расходов при равной депрессии);
- последовательная работа вентиляторов (суммирование депрессий при равном расходе).

**Определение рабочей точки** выполняется как пересечение напорной характеристики вентилятора с характеристикой сети; вычисляются коэффициент полезного действия и потребляемая мощность, контролируется выход режима за границы паспортной области.

### 2.5. Моделирование аварийных режимов при подземном пожаре

- задание очага пожара в произвольной выработке сети;
- расчёт мощности тепловыделения и температуры продуктов горения;
- расчёт **тепловой депрессии пожара** и её влияния на воздухораспределение;
- оценка риска **опрокидывания вентиляционной струи** в наклонных и вертикальных выработках;
- расчёт остывания продуктов горения по длине выработки с учётом теплообмена с породным массивом;
- расчёт распространения оксида углерода (CO), диоксида углерода (CO₂) и дыма по ветвям сети вниз по потоку;
- определение зон задымления и расчёт **дальности видимости** по закону Бугера (L = 3/μ);
- расчёт продолжительности выгорания горючей массы.

**Справочник горючих материалов** содержит характеристики семи типов пожарной нагрузки, характерных для подземных условий: горное оборудование и техника, кабельная продукция, конвейерная лента, деревянная крепь, горюче-смазочные материалы, уголь, а также позицию с произвольно задаваемыми параметрами. Для каждого материала заданы: удельные выходы CO, CO₂ и дыма, низшая теплота сгорания, линейная скорость распространения горения, удельная скорость выгорания.

### 2.6. Расчёт параметров взрыва

- расчёт параметров ударной воздушной волны при взрыве взрывчатых веществ и горючих газов;
- расчёт по **методике Садовского** с использованием приведённого расстояния и тротилового эквивалента;
- альтернативный расчёт по методике на основе Федеральных норм и правил;
- справочник взрывчатых веществ с теплотой взрывчатого превращения и тротиловым эквивалентом;
- определение избыточного давления во фронте ударной волны и границ зон поражения по степени воздействия.

### 2.7. Гидравлический расчёт противопожарного водоснабжения

- построение модели водопроводной сети рудника (трубопроводы, арматура, потребители);
- гидравлический расчёт по формуле Дарси-Вейсбаха с определением потерь напора;
- расчёт расходов и давлений в узлах и участках сети;
- моделирование работы насосного оборудования, регуляторов давления и запорной арматуры;
- расчёт водопотребителей: пожарных стволов, оросителей, распылителей, пеногенераторов;
- проверка обеспеченности требуемых расходов и напоров в точках водоразбора.

### 2.8. Расчёт маршрутов горноспасательных отделений и позиций ПЛА

- расстановка **позиций плана ликвидации аварий** на схеме сети;
- расчёт оптимальных маршрутов передвижения отделений ВГСЧ по алгоритму Дейкстры;
- учёт нормативных скоростей передвижения в зависимости от угла наклона выработки;
- учёт задымления и снижения видимости на участках маршрута;
- расчёт расхода кислорода дыхательных аппаратов и контроль времени защитного действия;
- формирование данных для оперативной части плана ликвидации аварий.

### 2.9. Визуализация вентиляционной схемы

- отображение схемы в видах **«План»**, **«Фронт»**, **«Профиль»** и в трёхмерном представлении с произвольным поворотом и наклоном;
- масштабирование и панорамирование, раздельное масштабирование по осям XY и Z;
- цветовая раскраска сети по расходу воздуха, скорости, депрессии, направлению движения, горизонтам;
- отображение направлений движения воздуха и числовых параметров непосредственно на ветвях схемы;
- управление видимостью слоёв: узлы, ветви, водопровод, позиции ПЛА, подписи;
- панель свойств выбранного объекта с редактированием параметров;
- панель информации с настраиваемым набором отображаемых величин.

Программа содержит встроенные справочники:
