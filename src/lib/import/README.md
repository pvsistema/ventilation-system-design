# Импорт схемы — карта форматов

Пункты меню «Файл → Добавить» и файлы, которые их обслуживают.
**Каждый формат — отдельный файл.** Если правите поведение импорта, сначала
найдите по таблице нужную строку: у разных программ форматы похожи по виду,
но разбираются по-разному.

| Пункт меню | Что за файл | Разбирает | Диалог |
|---|---|---|---|
| CSV из АэроСети | 5 файлов CSV, столбцы по заголовкам | `aerosetCsvImport.ts` | `CsvImportDialog.tsx` |
| CSV из Вентиляция 2.0 | 5 файлов CSV, столбцы задаёт пользователь | `vent2CsvImport.ts` | `Vent2CsvImportDialog.tsx` |
| Схема Вентиляция 2.0 | `.cdf3` — двоичный файл схемы | `vent2Cdf3Import.ts` | `Vent2Cdf3ImportDialog.tsx` |
| Модель Ventsim | `.vsm` — файл модели (gzip + текст) | `ventsimVsmImport.ts` | `VentsimVsmImportDialog.tsx` |
| CSV из Ventsim | Branch Report / Export to CSV | `ventsimCsvImport.ts` | `VentsimCsvImportDialog.tsx` |
| Схема из DXF | `.dxf` — чертёж (текст) | `../dxfImport.ts` | `DxfImportDialog.tsx` |
| Схема из DWG | `.dwg` — чертёж (двоичный) | `../dwgImport.ts` | `DxfImportDialog.tsx` |
| Excel (Вентиляция 2.0) | `.xlsx` | `../excelImport.ts` | `ExcelImportDialog.tsx` |
| DXF + Excel вместе | пара файлов | `../combinedImport.ts` | `CombinedImportDialog.tsx` |

## Общая часть

- `importCommon.ts` — типы результата импорта (`CsvImportResult`, `RawPosition`
  и прочие) и разбор ТЕКСТА CSV: строки, разделители, кавычки, горизонты,
  единицы сопротивления.
- `csvFieldUtils.ts` — разбор ОТДЕЛЬНЫХ ЗНАЧЕНИЙ: идентификаторы, числа в
  инженерной записи, цвета, обозначения вентиляторов.

Всё, что относится к конкретной программе, живёт в файле этой программы —
в общие модули такое класть нельзя, иначе форматы снова перепутаются.

## Правило именования

`<программа><Формат>` — сначала ПРОГРАММА, потом формат файла:

- `vent2…` — ПО «Вентиляция 2.0» (`vent2CsvImport`, `vent2Cdf3Import`);
- `ventsim…` — Ventsim Design (`ventsimCsvImport`, `ventsimVsmImport`);
- `aeroset…` — АэроСеть.

Имя формата само по себе (`cdf3`, `vsm`) как название файла НЕ используется:
`.cdf3` — это формат Вентиляции 2.0, а `.vsm` — Ventsim, и без префикса
программы их легко приписать не тому производителю. По этому же правилу
названы диалоги и типы результата: `Vent2Cdf3Result`, `VentsimVsmResult`.

## Две пары, которые легко спутать

**Вентиляция 2.0 отдаёт данные двумя способами**, и это РАЗНЫЕ файлы:

- `.cdf3` (Схема) — геометрия, топология, горизонты и перемычки с их
  сопротивлением. Сопротивления/расхода выработок, напоров вентиляторов и
  позиций ПЛА в файле нет вовсе (проверено поиском по всему файлу).
- CSV-выгрузка — есть сопротивления, расходы, перемычки, вентиляторы и
  позиции ПЛА.

**Ventsim — тоже два способа:**

- `.vsm` (Модель) — сопротивления и расходы ЕСТЬ.
- CSV-выгрузка — сопротивлений и расходов НЕТ.

## Грабли формата Вентиляции 2.0

Проверено на выгрузке рудника Весенний, 679 выработок и 61 позиция:

1. Позиции ПЛА выгружаются с координатами `0,0,0` — своего места не хранят.
   Оно вычисляется по серединам привязанных выработок.
2. Привязка позиции к выработкам лежит в файле ВЫРАБОТОК (столбец
   «Идентификатор позиции»), а не в файле позиций — там списка нет.
3. Вида аварии в выгрузке нет.
4. Цвет записан восемью знаками (`#00FFFF00`) — впереди прозрачность.
5. Сопротивление уже суммарное, вместе с перемычками: второй раз добавлять
   сопротивление перемычек нельзя.
