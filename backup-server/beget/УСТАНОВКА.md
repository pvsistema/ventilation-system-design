# Резервный сервер ПВ-Система на Beget — установка

Инструкция под ваш аккаунт: репозиторий `pvsistema/ventilation-system-design`,
домен `сервер.пвсистема.рф`.

---

## Про данные: копировать ничего не нужно

Резервный сервер выполняет только расчёты (воздухораспределение, аэродинамика,
горноспасательные, взрывы, водопровод). Он **не хранит** схемы, пользователей
и справочники — всё это остаётся в основной программе.

Схема на расчёт приходит с компьютера инженера, обратно возвращается результат.
Поэтому база данных резерву не требуется, синхронизировать нечего. Копируется
только сама программа расчётов — командой `git clone` из вашего репозитория.

---

## Шаг 1. Направить домен на сайт

Панель Beget → **Домены** → у домена `сервер.пвсистема.рф` кнопка «⋮» →
**«Направить на сайт»** → создать новый сайт, например `pvs-backup`.

Если домен ещё не добавлен: в поле вверху страницы «Добавление доменов»
он уже введён — нажмите **«Добавить домены»**.

## Шаг 2. Включить Python-приложение

Панель Beget → **Сайты** → у сайта `pvs-backup` → **«Приложения»** →
**Python** → версия **3.11** (или ближайшая).

Beget создаст структуру и будет запускать программу через Passenger —
он ищет файл `passenger_wsgi.py`.

## Шаг 3. Загрузить программу по SSH

Панель Beget → **Настройки** → включить SSH, затем подключиться
(терминал или встроенный веб-терминал Beget) и выполнить по очереди:

```bash
cd ~
git clone https://github.com/pvsistema/ventilation-system-design.git pvs-backup
cd pvs-backup
python3 backup-server/prepare.py
cp backup-server/beget/passenger_wsgi.py .
cp backup-server/beget/update.sh .
chmod +x update.sh
```

Установить библиотеки:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip
pip install -r backup-server/requirements.txt
```

## Шаг 4. Указать Beget папку приложения

В настройках Python-приложения:

- каталог приложения: `/home/ВАШ-ЛОГИН/pvs-backup`
- файл запуска: `passenger_wsgi.py`

Перезапуск приложения (нужен после любых изменений):

```bash
mkdir -p ~/pvs-backup/tmp && touch ~/pvs-backup/tmp/restart.txt
```

## Шаг 5. Включить SSL

Панель Beget → **Домены** → `сервер.пвсистема.рф` → **SSL** →
Let's Encrypt (бесплатно). Через несколько минут адрес откроется по `https://`.

Это обязательно: программа работает по защищённому протоколу и не сможет
обратиться к резерву по незащищённому адресу.

## Шаг 6. Проверить

Откройте в браузере:

```
https://сервер.пвсистема.рф/health
```

Ожидаемый ответ — строка со словом `ok` и списком из пяти расчётов
со значением `true`.

## Шаг 7. Подключить в программе

**Админ-панель → Сервер расчёта → Адрес аварийного сервера**:

```
https://сервер.пвсистема.рф/
```

→ «Проверить связь» → «Сохранить».

Готово. При сбое основного сервера или исчерпании вычислительного времени
расчёты автоматически уйдут на резерв.

## Обновление резерва

После правок в основной программе код уходит в GitHub. Чтобы обновить резерв:

```bash
bash ~/pvs-backup/update.sh
```

Скрипт сам загрузит свежую версию, обновит расчёты, доставит библиотеки
и перезапустит приложение.

### Обновление по расписанию

Панель Beget → **Планировщик задач (Cron)** → добавить задание
(например, еженедельно в 4 утра понедельника):

```
0 4 * * 1 bash ~/pvs-backup/update.sh >> ~/pvs-backup/update.log 2>&1
```

## Если что-то пошло не так

| Признак | Решение |
|---|---|
| «500 Internal Server Error» | Смотрите лог: `tail -50 ~/pvs-backup/tmp/*.log`. Обычно не установлены библиотеки — повторите шаг 3 |
| Страница `/health` не открывается | Перезапустите: `touch ~/pvs-backup/tmp/restart.txt` |
| «Расчётный модуль не найден» | Не выполнен `python3 backup-server/prepare.py` |
| В программе «Нет ответа» | Проверьте, что включён SSL и адрес начинается с `https://` |
| Репозиторий просит пароль | Он публичный, пароль не нужен — проверьте адрес репозитория |
| Домен не открывается | DNS ещё обновляется, подождите до 2 часов |
