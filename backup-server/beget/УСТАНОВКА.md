# Резервный сервер ПВ-Система на Beget — пошаговая установка

Инструкция под ваш аккаунт `sabitosh`:

- сайт: `server.pv-sistema.rf`
- домен: `сервер.пв-система.рф`
- репозиторий: `pvsistema/ventilation-system-design`

Сайт и домен у вас уже созданы — начинайте с шага 2.

---

## Про данные: копировать ничего не нужно

Резервный сервер только выполняет расчёты (воздухораспределение, аэродинамика,
горноспасательные, взрывы, водопровод). Он **не хранит** схемы, пользователей
и справочники.

Схема на расчёт приходит с компьютера инженера, обратно возвращается результат.
База данных резерву не нужна, синхронизировать нечего. Копируется только сама
программа расчётов — командой `git clone`.

---

## Шаг 1. Сайт и домен — уже сделано

В разделе **Хостинг → Управление сайтами** сайт `server.pv-sistema.rf` создан,
домен `сервер.пв-система.рф` к нему привязан. Пропускайте.

## Шаг 2. Включить Python-приложение

Панель Beget → **Хостинг** → **Управление сайтами** → у сайта
`server.pv-sistema.rf` нажмите «⋮» (три точки справа) → **«Приложения»**
(или значок шестерёнки).

Выберите **Python**, версия **3.11** (или ближайшая доступная).

Beget будет запускать программу через Passenger — он ищет файл
`passenger_wsgi.py` в корне приложения.

## Шаг 3. Включить SSH

Панель Beget → **Настройки** → раздел «Доступ по SSH» → включить.

Там же указаны данные для входа: сервер, логин `sabitosh`, порт.
Подключиться можно встроенным веб-терминалом Beget (кнопка рядом)
либо любой программой-терминалом.

## Шаг 4. Загрузить программу

В терминале выполните команды по очереди (каждую — Enter):

```bash
cd ~/server.pv-sistema.rf
rm -rf public_html
git clone https://github.com/pvsistema/ventilation-system-design.git public_html
cd public_html
python3 backup-server/prepare.py
cp backup-server/beget/passenger_wsgi.py .
cp backup-server/beget/update.sh .
chmod +x update.sh
```

Пояснение: папка `public_html` заменяется на копию программы. Она пустая,
терять там нечего.

## Шаг 5. Установить библиотеки

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install --upgrade pip
pip install -r backup-server/requirements.txt
```

Установка занимает 1–3 минуты.

## Шаг 6. Перезапустить приложение

```bash
mkdir -p ~/server.pv-sistema.rf/public_html/tmp
touch ~/server.pv-sistema.rf/public_html/tmp/restart.txt
```

Эти же две команды нужны после любых изменений.

## Шаг 7. Включить SSL

Панель Beget → **Домены** → у домена `сервер.пв-система.рф` → «⋮» →
**SSL** → **Let's Encrypt** (бесплатно).

Выпуск занимает несколько минут. Это обязательный шаг: программа работает
по защищённому протоколу и к незащищённому адресу обратиться не сможет.

## Шаг 8. Проверить

Откройте в браузере:

```
https://сервер.пв-система.рф/health
```

Ожидаемый ответ — строка со словом `ok` и пятью расчётами со значением `true`:

```
{"ok":true,"role":"backup","service":"pvs-compute","functions":{...}}
```

## Шаг 9. Подключить в программе

**Админ-панель → Сервер расчёта → Адрес аварийного сервера**:

```
https://сервер.пв-система.рф/
```

Нажмите «Проверить связь» → должно появиться зелёное «Резервный сервер
отвечает, все расчёты загружены» → «Сохранить».

Готово. При сбое основного сервера или исчерпании вычислительного времени
расчёты уйдут на резерв автоматически.

---

## Обновление резерва

После правок в основной программе код уходит в GitHub. Обновить резерв:

```bash
bash ~/server.pv-sistema.rf/public_html/update.sh
```

Скрипт сам загрузит свежую версию, обновит расчёты, доставит библиотеки
и перезапустит приложение.

### Обновление по расписанию

Панель Beget → **Планировщик задач (Cron)** → добавить задание,
например еженедельно в 4 утра понедельника:

```
0 4 * * 1 bash ~/server.pv-sistema.rf/public_html/update.sh >> ~/update.log 2>&1
```

Тогда резерв будет обновляться сам.

## Если что-то пошло не так

| Признак | Решение |
|---|---|
| «500 Internal Server Error» | Смотрите лог: `tail -50 ~/server.pv-sistema.rf/public_html/tmp/*.log`. Чаще всего не установлены библиотеки — повторите шаг 5 |
| Открывается пустая страница или список файлов | Не включено Python-приложение — вернитесь к шагу 2 |
| Страница `/health` не обновляется | Перезапустите приложение (шаг 6) |
| «Расчётный модуль не найден» | Не выполнен `python3 backup-server/prepare.py` |
| В программе «Нет ответа» | Проверьте, что SSL выпущен и адрес начинается с `https://` |
| Домен не открывается | DNS ещё обновляется — подождите до 2 часов |
| `python3: command not found` | Python-приложение не включено (шаг 2) либо используйте `python3.11` |

## Итог

После настройки у вас постоянный резервный адрес, доступный из любой точки
России, с настоящим SSL, без лимитов вычислительного времени и без зависимости
от офисного компьютера. Обновление — одной командой или автоматически.
